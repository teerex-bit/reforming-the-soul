# Reforming the Soul Brand System

## Brand Character
Depth without heaviness. Peace without passivity. Beauty without decoration for its own sake. Spirituality without cliché. Movement without urgency.

## Core Palette

| Token | HEX | Role |
|---|---|---|
| `--rts-navy` | `#06223A` | Primary structure, buttons, navigation |
| `--rts-navy-dark` | `#031D32` | Dark sections/backgrounds |
| `--rts-ivory` | `#FAF6EF` | Primary light page background |
| `--rts-ivory-alt` | `#F5EFE5` | Alternate light background |
| `--rts-gold` | `#C88A31` | Accent, rules, highlights |
| `--rts-gold-light` | `#E1B45F` | Secondary gold emphasis |
| `--rts-text` | `#13263A` | Primary dark text |
| `--rts-muted` | `#52606D` | Secondary text |

Page-specific colors should be sampled from approved source graphics and documented separately.

## Phase Color Families
- Awaken: sage / olive / warm natural tones
- See Clearly: blue family
- Become: purple / plum tones
- Join: teal / green-blue

Phase colors orient the visitor; navy + ivory + gold remain the parent brand.

## Typography
### Formation voice
Elegant serif for H1/H2, major assertions, quotations, questions.

### Interface voice
Clean sans serif for body copy, navigation, buttons, labels, captions.

### Script accent
Use sparingly and only when an approved treatment calls for it.

## Logos and Marks
- RTS logo: use supplied approved file; never generate an approximation.
- Tree of Life: preserve approved root/crown symmetry when it is meant to be recognized as the Tree of Life.
- Conversations: preserve its separate approved identity treatment.

## Journey Icons
Canonical locked icons:
1. Awaken
2. See Clearly
3. Become
4. Join

Do not substitute an older icon set for these four.

## Supporting Icons
Use existing RTS icon assets when appropriate. Create new supporting icons only when no approved asset fits and never to replace a locked symbol.

## Photography
Prefer natural, spacious, believable, contemplative imagery with warm directional light and a sense of movement, attention, truth, formation, presence, or invitation.

Avoid generic church stock, raised-hands worship stock, corporate training visuals, wellness/yoga clichés, or generic SaaS styling.

## Light and Dark Environments
### Light
Ivory, navy, natural photography, gold accents.

### Dark
Deep navy/near-black, white/ivory type, gold accent.

Music is an approved example of a dark expression. Do not alternate themes randomly.

## Whitespace
Whitespace is part of the brand. More text later in the journey should feel deeper, not busier.

## Buttons
Primary: strong contrast, normally navy/gold or ivory.
Secondary: quiet outline/text treatment.
Preserve approved CTA wording exactly.

## Cards
Use restrained backgrounds, subtle borders, minimal/no shadow, and generous padding.

## Page Color Documentation
Each completed page must document:
- section backgrounds
- text colors
- button colors
- card colors
- sidebar colors
- accents
- page-specific phase colors
