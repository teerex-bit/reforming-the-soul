# Reforming the Soul Site Architecture

## Purpose
The current public website is a guided overview of the Reforming the Soul framework, not the later comprehensive curriculum/LMS.

## Main Public Areas
Expected top-level areas:
- Soul Formation
- Conversations
- Books
- Music
- Writings / Teachings
- About

Exact menu wording may be refined later.

## Soul Formation
```text
Soul Formation
  ├── Awaken
  ├── See Clearly
  ├── Become
  └── Join
```

`Walk` / `Walk Daily` is not a fifth primary stage.

## Navigation Layers
### Global Navigation
Used across public pages.

### Formation Journey Navigation
Used inside Soul Formation.

Desktop:
- persistent/sticky side navigation where called for
- highlights current stage
- shows four-stage journey

Mobile:
- compact/collapsible form of same hierarchy

### Breadcrumbs
Use sparingly, e.g.:
```text
Soul Formation / See Clearly
```

Do not add LMS-style lesson numbering or progress mechanics unless later requested.

## Visual-to-Verbal Progression
### Awaken
Graphic-led, high whitespace, short prompts.

### See Clearly
Still visual, with increasing explanation.

### Become
More substantial teaching text, supported by visual anchors.

### Join
Integrated text and imagery serving participation/application.

This progression is intentional and must not be normalized away.

## Conversations
Relational, spacious, concise, with an eventual primary booking CTA. Preserve its approved identity treatment.

## Books
Catalog-oriented: calm hero, live intro copy, reusable book grid, cover assets, third-party purchase links later.

## Music
May use the approved darker navy/gold environment, with live text and media links/players later.

## Future Curriculum
May eventually include lessons, saved progress, accounts, exercises, reflections, and completion state. Do not build these into the current overview unless explicitly requested.
