# Backlog / Parking Lot

These items are intentionally not programmed in the Phase 1 vertical slice:

- Full Awaken, See Clearly, Become, or Join curriculum.
- Native iOS and Android clients.
- Public social feed, community, group chat, or team features.
- Mentor dashboard or blanket mentor access.
- Spiritual gifts assessment or calling assignment.
- Streaks, badges, leaderboards, fruit scores, or spiritual maturity scores.
- Advanced cross-history pattern analytics.
- General reminders or notification system beyond surfacing the open practice on return.
- Ecommerce, subscriptions, Books, or Music features.
- Production CMS/admin authoring.
- Public website redesign or changes to approved Overview pages.
- Production deployment choice until Cloudflare compatibility is proved.
- Export/account-deletion operations beyond the item-level deletion needed by the slice; schema must not prevent later implementation.
- Reopen or duplicate a closed practice.
- Production-grade notifications/reminders; Phase 1 only surfaces an existing unfinished practice on dashboard return.
- Live-provider AI evaluation beyond a synthetic, non-sensitive contract smoke test.
