# Project boundaries

Project name: Overview Website.

The current Reforming the Soul 40-page website is reference-only. Never edit, rename, move, delete, overwrite, or reorganize its files.

Keep all implementation, generated files, and documentation within this new project. Do not use symlinks, junctions, or hard links to source-site files. Copy selected webpage files independently; never move them. Change relative paths only in the copied Overview Website files.

Approved shared logos, icons, images, fonts, and other established visual assets may be referenced read-only without duplicate working copies. Never modify original assets to make this project work. Tools that write, optimize, format, clean, or generate files must target only this project and must never follow shared asset references to write to the original site.

Current authorized scope: the two-page public Awaken overview: Pay Attention and Notice What Is Driving You. Both are simplified copies inside Overview Website. Do not copy additional pages, begin See Clearly, rewrite original files, or decide which old pages to remove or combine without explicit instruction. Preserve all original pages, navigation, CSS, JavaScript, assets, and configuration, including unused files. Do not refactor the original site.

Preserve existing backups. Any future backup must use a new unique destination and stop if that destination already exists.

Do not connect this project to the existing site's deployment or publish over the current site.
